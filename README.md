# H2 Physics Flashcards

Pink theme: #FCBACB. Static website for GitHub Pages.

## Important upload instructions
Upload these files directly into the repository root (not inside a nested folder):
- `index.html`
- `cards.js`

Keep the filenames exactly as written, especially `cards.js` (not `cards (1).js`). The HTML now shows a clear warning if the question bank cannot be loaded.

## Publish / update on GitHub Pages
1. Open the repository.
2. Replace `index.html` and `cards.js` using Add file → Upload files, or open each file and use Edit.
3. Commit the changes to `main`.
4. Wait for GitHub Pages to redeploy, then hard refresh the site (Ctrl+F5 on Windows; Cmd+Shift+R on Mac).

Progress is stored locally in the browser on each device; it does not sync between devices.
